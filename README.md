# NBBF-Control-Documents

Canonical control documents for the Node-Based Budget Framework (NBBF).

This repository defines the authoritative structural rules governing:
- Node-scoped budgeting
- Authority boundaries
- Fiscal exit conditions
- Sunset and renewal mechanics
